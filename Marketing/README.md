# Marketing — Lab Files

Lab materials for the Marketing track: **BAT Marketing Copilot CIE — Hands-on
Lab Guide** (Copilot Apps + Agent Builder, for Marketing Managers).

> **Synthetic training material.** The *Shape What's Next* campaign, markets,
> research figures, policies, contacts and approval routes in these files are
> fictional and are not official BAT information. This is a corporate /
> employer-brand scenario for adult audiences (21+) only — never create content
> promoting tobacco or nicotine products, and do not use real campaign,
> customer or employee data during the exercises.

**[BAT_Marketing_Copilot_CIE_Lab_Guide.pdf](BAT_Marketing_Copilot_CIE_Lab_Guide.pdf)** — the full lab guide.

## Setup

1. Download the files (use **Code → Download ZIP** on the repository home page).
2. Save a working copy of each file in the training location your facilitator gives you.
3. Keep the four agent knowledge documents together in one OneDrive or SharePoint
   folder if your environment supports folder-based grounding.
