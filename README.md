# BAT CIE — Hands-on Lab Files

Welcome. This repository holds the files for today's hands-on labs.

## Getting the files

**Option 1 — Download everything (easiest, no account needed)**

1. Click the green **Code** button at the top of this page.
2. Choose **Download ZIP**.
3. Unzip it somewhere easy to find, such as your Desktop.

**Option 2 — Clone with Git**

```bash
git clone https://github.com/sara-el-sayed/bat-cie-labs.git
```
