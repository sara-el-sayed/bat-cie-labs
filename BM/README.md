# BM (TM&D) — Lab Files

Lab materials for the Trade Marketing & Distribution track: **BAT TM&D Copilot
CIE — Hands-on Lab Guide** (Copilot Apps + Agent Builder, for Trade Managers).

> **Synthetic training material.** All markets, performance figures, policies,
> contacts and scenarios in these files are fictional and are not official BAT
> information. Do not use real customer, trade, commercial or financial data
> during the exercises.

## Start here

**[BAT_TMD_Copilot_CIE_Lab_Guide.pdf](BAT_TMD_Copilot_CIE_Lab_Guide.pdf)** — the full lab guide.

| Part | Activity | Time |
| --- | --- | --- |
| A | Choose two Copilot app exercises | 20 minutes |
| B | Build the BAT Trade Business Review Guide agent | 25 minutes |
| C | Test and improve the agent | 5 minutes |

## Setup

1. Download the files (use **Code → Download ZIP** on the repository home page).
2. Save a working copy of each file in the training location your facilitator gives you.
3. Keep the four agent knowledge documents together in one OneDrive or SharePoint
   folder if your environment supports folder-based grounding.
