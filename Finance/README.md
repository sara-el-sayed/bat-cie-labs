# Finance — Lab Files

Lab materials for the Finance track: **BAT Finance Copilot CIE — Hands-on Lab
Guide** (Copilot Apps + Agent Builder, worked in pairs).

> **Synthetic training material.** Region Atlas and every market, person,
> figure, threshold, policy and contact in these files are fictional and are not
> official BAT information, policy or financial results. Do not use real
> financial, market or employee data during the exercises.

## Start here

**[BAT_Finance_Copilot_CIE_Lab_Guide.pdf](BAT_Finance_Copilot_CIE_Lab_Guide.pdf)** — the full lab guide.

| Part | Activity | Time |
| --- | --- | --- |
| A | Excel Copilot (mandatory) + one of Word, PowerPoint or Teams | 20 minutes |
| B | Build the BAT Finance Performance Guide agent | 25 minutes |
| C | Swap with a partner pair: test and improve the agent | 5 minutes |

## Setup

1. Download the files (use **Code → Download ZIP** on the repository home page).
2. Save the workbook to OneDrive and open it in Excel for the web or desktop with
   AutoSave on, so Copilot is available.
3. Keep the four agent knowledge documents together in one OneDrive or SharePoint
   folder if your environment supports folder-based grounding.
